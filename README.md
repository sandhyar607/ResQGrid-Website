# 🚨 ResQGrid – AI-Powered Multi-Agent Crisis Resource Allocation

### Intelligent Resource Distribution for Disaster Management

ResQGrid is an AI-powered multi-agent crisis resource allocation platform designed to support disaster management by intelligently coordinating and distributing limited electricity resources among critical services such as hospitals, water supply systems, emergency services, and telecommunications.

The platform uses a multi-agent negotiation approach to help prioritize emergency requirements, coordinate resource requests, and improve decision-making during crisis situations.

---

## 🌍 Problem Statement

During natural disasters and emergency situations, essential services often face electricity shortages. Hospitals, water pumping stations, emergency response teams, and communication networks compete for limited power resources.

Traditional manual allocation methods can be slow and difficult to manage during rapidly changing emergencies.

ResQGrid aims to reduce manual workload through intelligent multi-agent coordination and automated resource allocation.

---

## 💡 Our Solution

ResQGrid provides an integrated platform where AI agents coordinate resource requirements and negotiate for available electricity based on priority, urgency, and resource availability.

### Key Features

- **Multi-Agent Negotiation:** Multiple service agents coordinate and negotiate for limited electricity resources.
- **Intelligent Priority Assessment:** Evaluates resource requests based on urgency and critical service requirements.
- **Automated Resource Allocation:** Supports optimized distribution of available electricity.
- **City Monitoring Dashboard:** Provides a centralized view of affected areas and critical infrastructure.
- **Real-Time Monitoring Interface:** Displays electricity availability and resource allocation information.
- **AI Chatbot Assistant:** Allows users to communicate using natural language and request system actions.
- **Public and Government Access:** Provides separate interfaces for public users and authorized government users.
- **Crisis Management Support:** Helps coordinate essential services during emergency situations.

---

## 🤖 Multi-Agent System

The core concept of ResQGrid is autonomous multi-agent negotiation.

Different service agents represent critical infrastructure, including:

1. Hospital Agent
2. Water Supply Agent
3. Emergency Services Agent
4. Telecommunications Agent

Each agent communicates its electricity requirements and priorities.

The agents participate in a negotiation process to determine resource distribution under limited electricity capacity.

The system aims to balance:
- Critical service requirements
- Emergency priorities
- Available electricity
- Resource constraints
- Fairness in allocation

## 🏙️ City Monitoring Dashboard

The City Monitoring Dashboard provides a centralized interface to monitor affected areas and essential services.

## 💬 AI Chatbot Assistant

ResQGrid includes a natural-language chatbot interface designed to simplify interactions with the platform.

Users can communicate their requirements through normal conversations instead of navigating multiple forms.

The chatbot is intended to assist with:
- Understanding resource requirements
- Submitting requests
- Accessing relevant information
- Supporting crisis management workflows

Government-related actions are restricted to authorized government users.
